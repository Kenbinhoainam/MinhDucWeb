# Việc làm Minh Đức — Premium V11

This is a **multifile, offline demo prototype** upgraded from V10. Ten HTML pages, CSS, JS, AI illustrative WebP images and an in-browser CMS are preserved.

## New
- Project-local `.agents/skills/frontend-design/SKILL.md` transcribed from the official public source and accompanied by its Apache-2.0 license; direct upstream clone was unavailable in this environment.
- Npm/skills install scripts for online Windows/Linux machines. UI/UX Pro Max CLI **is not installed in this ZIP** because the build environment could not reach npm registry.
- Design-system specification with six tokens, accessibility and art-direction notes.
- Refined V11 CSS for hierarchy, composition, forms, cards, button states, mobile actions, reduced motion.
- Audit with conservative per-category scoring, documentation of nonproduction requirements.

## Run
Double click `START-WINDOWS.bat` if Python installed, or start `python -m http.server 8000` in project folder. Open `http://localhost:8000/index.html`; CMS at `/quan-tri.html`.

## Complete skill installation after download
Run `INSTALL-DESIGN-TOOLS.bat` (requires Node/npm, internet); verifies skills with `.agents/skills/` folder. The CLI package is `ui-ux-pro-max-cli`, not `uipro-cli`. You may instead execute commands shown in `DESIGN-SYSTEM-V11.md`.

## Important
AI industrial photographs are illustrations only. All employers/partners and KPIs must be validated by Minh Đức before tender material or a public launch. Backend, security, privacy, and Google Sheets integration remain out of scope for this HTML prototype.
